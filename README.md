# Видеограф — прототип стиля

6 вариантов оформления одного сайта: `kino/` — Кино тёмный, `label/` — Лейбл, `fashion/` — Fashion, `editorial/` — Редакционный, `bright/` — Яркий брендовый, `yellow/` — Чёрно-жёлтый (правится вручную, не через `_build`).

Страница выбора — `index.html`. Видео, тексты и цены — заглушки.
