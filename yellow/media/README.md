# Тизеры и обложки работ

Сюда кладём файлы для блока «Работы», затем прописываем путь в `videos` в `yellow/index.html`
(поля `teaser` и `cover`, например `teaser: 'media/gunwest.mp4'`).

- **Тизер** — `.mp4`, 5–8 секунд, H.264, 1280×720, без звука, до 3 МБ. Играет при наведении (на телефоне — когда карточка на экране).
- **Обложка** — `.jpg`, 1280×720, яркий кадр из ролика. Видна, пока тизер не играет.
